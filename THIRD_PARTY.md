# Dependencies and provenance

This repository contains original application/adaptation code and minimized extracts of the author’s existing synthetic shopping tasks/profiles. No private harness implementation, real customer dataset or third-party source dependency is vendored. Anthropic SDK, Playwright and their transitive packages are installed from their public distributions and retain their own licenses. PayPal names identify the sandbox API integration; no affiliation or endorsement is claimed.

Final video narration uses local synthetic speech; no copyrighted background music was added. Source hashes refer to historical full files, while fixtures/manifest.json hashes the minimized extracts shipped here.
